# Java Complete: Object-Oriented Programming & Projects

This repository contains my studies, exercises, and projects developed during the comprehensive Java course taught by Prof. Nélio Alves. The goal is to master modern Java, object-oriented concepts, and software development best practices.

## 🚀 Key Topics Covered

* **Object-Oriented Programming (OOP):** Classes, attributes, methods, overloading, encapsulation, and inheritance.
* **Polymorphism & Casting:** Upcasting, downcasting, `@Override` annotation, and the `super` keyword.
* **Memory Management:** Arrays, lists, and boxing/unboxing behavior.
* **Advanced Concepts:** Enumerations, composition, exceptions handling, generics, and Lambda expressions.
* **Database & Web:** JDBC for database connectivity and Spring Boot framework integration.

## 🛠️ Tech Stack & Tools

* **Language:** Java 17 / 21
* **IDE:** Eclipse (STS)
* **Version Control:** Git & GitHub
